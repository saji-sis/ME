# Sajjad Sistani — Personal Portfolio

A responsive, bilingual (English / فارسی) two-page personal portfolio built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home, selected projects and contact
- `me.html` — About, skills, toolkit and contact

## Features
- English / Persian language toggle with RTL/LTR layout
- Dark / light theme toggle
- Language and theme preferences saved in local storage
- Responsive mobile layout
- No build step, package manager or backend required

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. The site should be available at https://saji-sis.github.io/ME/ after deployment completes.
