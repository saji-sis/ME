# Sajjad Sistani — Personal Portfolio

A responsive, bilingual (English / فارسی) single-page personal portfolio.

## Features
- One-page layout: introduction, selected projects, about, skills and contact
- English / Persian language toggle with RTL/LTR layout
- Dark / light theme toggle
- Animated headline and continuously moving technology-logo marquee
- Responsive layout and reduced-motion accessibility support
- No build step or package manager required

## Publish with GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Expected URL: https://saji-sis.github.io/ME/
